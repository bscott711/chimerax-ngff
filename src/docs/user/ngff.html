Opening OME-Zarr (OME-NGFF) images

The ChimeraX-NGFF bundle opens local OME-Zarr stores (folders named *.zarr, usually *.ome.zarr) as volume data. Use the command 

open path/image.ome.zarr

or File > Open Folder..., or drag the folder onto the ChimeraX window. The format name is OME-Zarr (NGFF) and its nickname is ngff, so open path format ngff forces it (needed for a folder whose name does not end in .zarr).

Option:

  • series name – open this series group of a bioformats2raw store (for example series 1) instead of the image the store describes at its root.

Time points become a volume series (play them with the slider or vseries commands) and channels become separate coloured volumes. Lower resolution levels are used automatically when ChimeraX shows the data at a coarser step, so large images open without reading the full resolution data. Voxel sizes are used in the units the store gives (for example micrometres), as for OME-TIFF.

Supported: zarr v2 and v3 (including sharding), OME-NGFF 0.1 to 0.5, bioformats2raw layouts, and plain zarr arrays. Not supported in this version: remote stores (http, s3), labels, and HCS plates.
